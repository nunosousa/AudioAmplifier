# UI visual references

`retro-dsp-ui-reference.png` is a user-provided visual direction reference for
the front-panel UI. It captures the intended retro instrumentation language
and the six principal display views. It is not a final layout, source asset,
or authoritative representation of DSP parameter values.

The active interaction and display requirements are in `../FRONT_PANEL.md`;
the implementation boundaries are in `../UI_FIRMWARE_ARCHITECTURE.md`.
